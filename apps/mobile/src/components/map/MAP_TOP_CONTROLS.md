# Map top controls

Primary controls are intentionally pinned directly below the safe area:

1. horizontally scrolling People / Events / Listings / Alerts / More chips
2. fixed GPS recenter action on the right
3. weather / location-recovery chrome
4. optional challenge and nudge cards
5. Trending nearby

The centered bottom-tab `+` remains the canonical create action. The lower-right map recenter FAB was removed to keep lower discovery rails unobstructed.
